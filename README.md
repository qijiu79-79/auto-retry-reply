# 空回 / 道歉自动重试（免补丁版）

SillyTavern 独立扩展，版本 **1.1.4**。不修改酒馆源码、预设或提示词，无须重启酒馆服务。

## 安装与一键更新

在酒馆的 **扩展 → 安装扩展** 中粘贴：

```text
https://github.com/qijiu79-79/auto-retry-reply
```

安装后刷新页面，在扩展设置里找到“空回 / 道歉自动重试（免补丁版）”。以后在扩展管理里点击本扩展的更新按钮，更新后在没有生成任务时刷新页面。

1.1.2起，插件自己的栏目也有“检查更新”和“安装更新”按钮，使用与“管理扩展程序”相同的酒馆更新接口。检查不会直接安装；安装成功后自动刷新页面。如果仍在生成/等待自动重试、有未发送草稿或正在编辑消息，会等待安全后再刷新，也可点“取消自动刷新”稍后自行刷新。最新版、检查失败或安装失败不会自动刷新。不添加后台定时更新，不改你保存的重试设置。

1.1.3修正本插件按钮被酒馆默认样式挤成竖排的问题；窄屏时按钮整块换行，不影响其他插件。

1.1.4修正Carbon在后台断线时可能连续耗尽取回机会的问题：连接报错后如果页面仍在后台，等待回到前台再取回同一次生成，不另外生成。健康连接不因切页被打断，手动停止和切换聊天仍会取消等待。缓存仍为10分钟，原自动重试设置不变；这是模拟回归验证，不代表所有手机Safari后台行为均已实机验证。

如果已经手动放入过同名 `auto-retry-reply` 文件夹，旧目录没有 Git 信息，首次迁移需要先把**这个扩展目录**移到酒馆扩展目录以外作备份，再通过上面的地址安装。不要同时加载两份，也不要删整个 extensions 目录。只替换同名扩展、保留酒馆设置时，原 `auto_retry_reply` 设置沿用；不需要重新导入预设。

## 普通功能

- 单角色聊天：空回、只有思考、或整条正文少于 1000 字符并命中道歉/拒答关键词时，自动创建新的回复版本，保留旧回复。
- 普通请求在满足条件时重试网络/临时 API 错误，最多次数、间隔、关键词均可设置。
- 群聊、quiet、impersonate 及无关网络请求不处理。
- 手动停止、切换聊天和修改设置会取消本轮重试；认证失败、余额不足和明确内容限制不重试。
- 普通流式已经交付有效数据后出错，不拼接第二次生成，保留已有片段并停止本轮重试。

**重新生成可能额外收费。** 默认最多 20 次额外重试、间隔 2 秒；请按自己的需求调整。短回复中的正常道歉台词也可能触发关键词规则。

## Gemini 保护入口（需要配套服务端）

此版本还带有配套服务端的 Gemini 适配，只在现有反代地址为 `https://api.doggego.online`、对应模型及工具预设匹配时启用；不改变保存的地址或 Key，不把请求改投到其他服务。

- Argon：由脚本标记决定首次请求走普通线路、自动重试走保护线路，不额外按 Key 分流；历史签名可继续触发保护。
- Carbon：脚本命中的保护请求断线时，重新连接**同一次生成**来取回结果，不重新提交生成。完整结果服务端最多暂存 10 分钟。
- 后台页面不累计心跳失联时间；连接已报错时等回到前台再取回，不在后台连续耗尽取回次数。尚未报错的连接回前台仍保留原宽限。完整终止帧到达后即可结束，不再死等 HTTP EOF。
- 桥已记录并结束的普通 API 报错重新交给原重试规则，包括这类已确认回传的 502/504；原次数、间隔、API重试开关及空回/道歉规则不变。失败尝试本身仍可能消耗额度，重新生成仍可能额外收费。
- 单纯断线先取回原结果；缓存缺失、内部回传中断或结果状态未知时，仍停止自动重新生成。没有桥确认标记的代理层502/504不会被冒充为已记录的普通错误。

配套服务端0.3.3起，两项功能都不再设置额外的Key白名单；仍需有效的NewAPI Key及对应模型权限，不是免鉴权接口。各Key的取回结果独立隔离，不能读取或取消他人的结果。此调整仅在服务端生效，已安装本版扩展的用户不必改预设或另外申请功能权限。仓库不包含服务端程序、密钥或聊天数据。

1.1.2的Carbon报错重试修补需配套桥0.3.4；新版桥先上线、客户端再更新即可。旧客户端在新版桥上仍沿用旧行为，朋友也需要先在“管理扩展程序”里更新并在空闲时刷新，才能看到新增按钮。Argon沿用原先的首次普通线路、后续保护线路以及原有网络/API错误重试规则，没有另加一套限制。

停止会尽力取消取回任务，但上游可能已接受并继续结算，不能保证停止就不收费。整页重载、服务重启、结果过期、鉴权变化或持续断网都可能导致无法取回。未宣称所有 iPhone Safari 后台场景均已实机验证。

## 测试与维护

无需安装依赖，使用 Node.js 20 或更新版本：

```sh
npm test
```

测试仅使用合成数据和假请求，不调用模型。可选 `AUTO_RETRY_CORE_SOURCE` 指定本机酒馆 `public/scripts/openai.js` 的绝对路径，运行额外的核心兼容检查；未指定时该项跳过。当前适配以酒馆 1.19.0 接口为基线，未来酒馆接口变动仍可能需要更新扩展。
